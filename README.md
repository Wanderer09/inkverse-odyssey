# InkVerse Odyssey · 墨语奇旅

**小学文言文启蒙学伴：借助注释读懂，用自己的话表达，让教师看见具体的学习卡点。**

[在线体验](https://wanderer09.github.io/inkverse-odyssey/) · [GitHub 仓库](https://github.com/Wanderer09/inkverse-odyssey)

学生界面以「小古文」为名，学伴「小竹」陪伴学生完成读原文、说句意、讲故事的学习旅程。InkVerse Odyssey 把古文的墨色与探索旅程结合起来，作为项目的英文名字。

![小古文书房](docs/assets/demo-home.png)

## 三分钟体验

1. 选择《司马光》，点击课文中的词语，查看拼音、注释与追问。
2. 完成两个句意挑战。可以故意选错一次，体验回看原文的提示。
3. 借助「开始—经过—结果」支架，用自己的话讲故事，修改后再提交。
4. 进入「教师记录台」，使用演示口令 **`246810`**。查看错答、求助与复述的原始表达，填写观察、更新跟进状态、导出 CSV。
5. 也可点击「预览合成演示数据」，查看带明确标签的虚构案例；这类数据不计入学习统计。

四篇课程：《司马光》《王戎不取道旁李》《精卫填海》《守株待兔》。古文原文来自传统文献，注释、学习任务、反馈支架及界面为本项目编写。原始讲义、比赛通知、学习记录和密钥均不随仓库发布。

## 在线演示的边界

GitHub Pages 版完全在浏览器运行，无需 API 密钥。学伴使用课程支架规则提供提示，复述反馈是表达线索检查，**需要教师复核**；在线版未接入真实大模型。

记录保存在当前浏览器的本地存储中，刷新可以继续学习。教师端只能查看同一浏览器中的记录，不能收集其他设备或班级的数据。清除站点数据会删除记录；浏览器禁用存储时会显示临时模式。演示口令只是角色入口，不提供真实账号隔离。请使用虚构学习内容体验。

查看注释是一种学习策略，不自动记为困难。系统保留错答、求助与复述证据，由教师决定是否需要跟进，不进行学生能力排名。

## 本地运行

安装 Node.js 22.9 或更高版本，不需要安装 npm 依赖。

```sh
npm test
npm run build:demo
npm run preview:demo
```

打开 `http://127.0.0.1:3211/inkverse-odyssey/`。预览使用与 GitHub Pages 相同的项目子目录。

仓库也保留服务端版本：`npm start` 后打开 `http://127.0.0.1:3210`。服务端保存学习数据，并可配置国产大模型接口。详见 [本地服务端运行说明](docs/本地运行.md) 和 [智能体设计](docs/智能体设计.md)。真实模型服务需要自己的账号与密钥；已有模型测试使用模拟接口，不代表真实服务实测。

## 部署与验证

推送到 `main` 后，GitHub Actions 运行测试、构建静态文件并部署到 Pages。工作流只上传 `dist/` 中的网页资产。详见 [Pages 部署说明](docs/Pages演示部署.md)。

12 项自动测试覆盖学习闭环、四篇课程、教师复核与导出、会话边界、刷新持久化、删除、存储异常、模型适配与静态构建。另以浏览器验证学生和教师流程、CSV 下载、桌面与手机布局。截图使用自行编写的演示表达，不是实际课堂数据。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `content/lessons.mjs` | 古文、注释、理解题与复述支架 |
| `agent/teaching.mjs` | 浏览器和服务端共用的课程提示与表达线索检查 |
| `agent/core.mjs` | 智能体提示词、模型适配和反馈校验 |
| `demo/runtime.mjs` | 浏览器学习状态与教师记录 |
| `public/` | 学生书房、学习界面和教师记录台 |
| `server.mjs` | 可选的本地服务端 |
| `scripts/build-demo.mjs` | 生成九个静态网页文件 |
| `.github/workflows/pages.yml` | 测试、构建、部署工作流 |
| `tests/` | 服务端与浏览器演示的业务验证 |
