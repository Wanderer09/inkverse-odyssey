# 本地服务端运行

安装 Node.js 22.9 或更高版本，运行 `npm start`，访问 `http://127.0.0.1:3210`。Windows 也可双击根目录 `start.cmd`。无需安装 npm 依赖，默认提供课程规则支架。

服务默认仅监听本机。学习记录保存在 `data/learning.json`，不会作为静态文件公开。教师演示口令为 `246810`。正式使用需修改口令并建立真实账号管理；当前版本适合本机展示。

## 可选模型接口

将根目录 `.env.example` 复制为 `.env`，填写服务商提供的完整 `MODEL_ENDPOINT`（`/chat/completions` 地址）、`MODEL_NAME` 与 `MODEL_API_KEY`。确认使用方授权及服务商数据处理政策后，启用 `MODEL_DATA_CONSENT=true`，修改 `TEACHER_PIN` 并重启服务。

配置示例采用千问兼容接口；请按账号地域确认接口和可用模型。可参考 [服务商官方兼容接口文档](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions)。密钥仅保存在服务端，`.env` 不应提交到 GitHub。

模型请求包含课程上下文、学习阶段和经过基本脱敏的学生表达。基本脱敏无法覆盖所有个人信息，请使用学习编号。服务默认超时 25 秒，不自动重试扣费请求；模型不可用或反馈格式不合格时，会明确降级到课程支架。

`agent/core.mjs` 保存角色与约束、提示词、模型请求及证据校验。开放表达反馈用于辅助教师，不能独立判定学生理解水平。现有测试使用模拟模型接口，真实服务接入仍需实测。

## 验证

运行 `npm test`。测试覆盖完整学习流程、会话隔离、教师复核、CSV 导出、删除、重启持久化、模型请求与输出证据校验、异常降级，以及浏览器演示的存储和静态构建。

GitHub Pages 只部署浏览器演示，`npm start` 的服务端不会由 Pages 托管。
