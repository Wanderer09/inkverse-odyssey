# 课程来源与整理说明

十四篇课内选文的年级册次依据用户提供的三至六年级学习目录，六年级按该目录标注新版。本项目未复制教材页、练习册的现代译文、注释、插图和教学设计；注释、理解挑战、人物追问与感悟支架为本项目编写。

## 原文核对

《司马光》《守株待兔》《精卫填海》《王戎不取道旁李》《囊萤夜读》《铁杵成针》《古人谈读书》《杨氏之子》《自相矛盾》《两小儿辩日》《曹冲称象》《学弈》的古文依据用户已有讲义中的原文核对。原始讲义不随公开仓库发布。

《古人谈读书》当前包含《论语》三句及朱熹读书“三到”一段；《曹冲称象》采用《三国志》中称象的古文选段。原文选段和标点并非对每个新版教材的逐页复刻，教学时请对照实际教材。

《少年中国说（节选）》采用梁启超原文的少年责任、意象描绘与结尾祝愿段落，参照 [维基文库所录原作](https://zh.wikisource.org/wiki/少年中國說)。

《关尹子教射》原文出自《列子·说符》，对照 [古文岛原文页](https://m.gushiwen.cn/shiwenv_d65ec6893e7d.aspx)，未采用其现代译文、赏析和注释。

“岐嶷”的拼音核对 [中国哲学书电子化计划词典](https://ctext.org/dictionary.pl?char=岐嶷&if=en)，用于幼年聪慧义时标为 qí nì。“干将”在宝剑名义中标为 gān jiāng。注音提示服务于具体语境，不能脱离原句理解多音字。

## 课外附件

用户提供PDF《小学生必读小古文100篇（全）及释义（网盘免费下载打印）》作为此次整理依据，补充了原[微信资料入口](https://mp.weixin.qq.com/s/w9qKPnqRsDTKzt28itSbBw)无法读取正文的问题。附件标题与先前所称《小学生小古文100课》不同，本项目不据此认定作者或版本相同。

按附件保留100个编号、原题名和五组主题，每组20条。第49—60、92—100条共21条属于古诗词；另有文言文节选。课外阅读程度为项目提供的选读提示，不代表教材年级要求。进阶选段建议教师陪读。完整清单见[课外课程目录](课外课程目录.md)。

附件有三个原文相同的编号组：003《刻舟求剑》与074《察今》、025《陈太丘与友期》与080《期行》、035《讳疾忌医》与064《扁鹊见蔡桓公》。全部保留独立编号与学习记录，并显示互相对应的提示。因此100条对应97种原文选段。

导入古文、古诗原文，清理PDF中混入的偏旁字符，保留中文标点；第053条《早发白帝城》的译文标记被PDF换行拆开，提取时剔除译文。98条正文与附件提取结果的SHA-256指纹一致，另两条作了以下校订。附件及现代译文、推广文字不随公开仓库发布。字词注释、问题、表达支架和感悟任务由本项目编写，不把整篇译文作为默认答案。

## 校订与阅读提示

- **071《口技》**：附件误串入“爷娘闻女来，自刭死矣”等句。对照[林嗣环《口技》原作](https://zh.wikisource.org/wiki/口技)，保留火起众声及宾客反应的短选段，中间作节选；页面明确标注校订与节选。
- **075《画地为牢》**：附件引句与解释不符原典。对照[司马迁《报任少卿书》](https://zh.wikisource.org/wiki/報任少卿書)校订为“故士有画地为牢，势不可入，削木为吏，议不可对，定计于鲜也”，任务讨论尊严与受辱的态度，不沿用附件的上古诚信解释。
- **036《欧阳修画荻教子》**：保留附件题名，页面说明原文是欧阳修母亲画荻教他，不是欧阳修教自己的孩子。
- **060《鹿柴》**：题中的“柴”读zhài；097诗题中的“左迁”解释为被贬官。

重点多音字按句中意义标音，例如004《郑人买履》的“度”区分测量duó与尺码dù，补充鸿鹄、缴、卮、巘、昳丽、毳衣等阅读提示。“毳衣”的cuì yī及毛制衣义参照[教育部重编国语辞典](https://dict.revised.moe.edu.tw/dictView.jsp?ID=142594&la=1&powerMode=0)；[“柴”字检索](https://dict.revised.moe.edu.tw/searchR.jsp?ID=4&ID=6&ID=75&la=0&powerMode=0&word=%E6%9F%B4)收录《鹿柴》的lù zhài读音。

字词注释聚焦学习任务与部分难字，不等同于逐字完整训诂。原文选段依附件整理，教师可结合实际读物补充上下文。涉及神话、古代诊疗与历史生活条件的文字，页面提供相应阅读提示。
