# 课程来源与整理说明

十四篇课内选文的年级册次依据用户提供的三至六年级学习目录，六年级按该目录标注新版。本项目未复制教材页、练习册的现代译文、注释、插图和教学设计；注释、理解挑战、人物追问与感悟支架为本项目编写。

## 原文核对

《司马光》《守株待兔》《精卫填海》《王戎不取道旁李》《囊萤夜读》《铁杵成针》《古人谈读书》《杨氏之子》《自相矛盾》《两小儿辩日》《曹冲称象》《学弈》的古文依据用户已有讲义中的原文核对。原始讲义不随公开仓库发布。

《古人谈读书》当前包含《论语》三句及朱熹读书“三到”一段；《曹冲称象》采用《三国志》中称象的古文选段。原文选段和标点并非对每个新版教材的逐页复刻，教学时请对照实际教材。

《少年中国说（节选）》采用梁启超原文的少年责任、意象描绘与结尾祝愿段落，参照 [维基文库所录原作](https://zh.wikisource.org/wiki/少年中國說)。

《关尹子教射》原文出自《列子·说符》，对照 [古文岛原文页](https://m.gushiwen.cn/shiwenv_d65ec6893e7d.aspx)，未采用其现代译文、赏析和注释。

“岐嶷”的拼音核对 [中国哲学书电子化计划词典](https://ctext.org/dictionary.pl?char=岐嶷&if=en)，用于幼年聪慧义时标为 qí nì。“干将”在宝剑名义中标为 gān jiāng。注音提示服务于具体语境，不能脱离原句理解多音字。
